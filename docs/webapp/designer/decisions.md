# Design Decisions

This page was a log of design decisions for the polis.pub interface, with the reasoning behind each. It has been retired because the current interface reverses several of its entries, so reading it as a guide would mislead. The current design is described in [brand](brand.md), [navigation](navigation.md) and [pages](pages.md). The last full version is at [v0.66.0](https://github.com/vdibart/polis-cli/blob/v0.66.0/docs/webapp/designer/decisions.md).
