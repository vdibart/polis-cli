# Storage Adapter

This page described a storage adapter interface for the discovery service, and a guide to writing a custom adapter against it. It has been retired: the interface it documented no longer exists in that form, and the discovery service source it pointed into is not public, so a reader could act on none of it. For what the discovery service does, see the [discovery service docs](../README.md). The last full version is at [v0.66.0](https://github.com/vdibart/polis-cli/blob/v0.66.0/docs/ds/developer/storage-adapter.md).
